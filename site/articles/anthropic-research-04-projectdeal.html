Project Deal（让 AI 代理替你讨价还价）

2023-11-03约 3 分钟Anthropic
阅读原文
中文摘要
Anthropic 在旧金山办公室搭了一个由 AI 代理替员工买卖闲置物品的市场：69 人、一周、186 笔真实交易。更强的模型谈成了更好的价格，但参与者几乎察觉不到自己被代表得好不好。

实验设置

2025 年 12 月，Anthropic 在旧金山办公室做了一个类似分类广告的市场，规则只有一条：所有交易都由代表员工的 AI 模型完成。

  • 招募 69 名员工，每人 100 美元预算，实验后按买卖结果结算
  • Claude 先做一次入职访谈，问清想卖什么、期望价格、想买什么、愿意出多少，以及对谈判风格的要求
  • 这些回答被写成每个人专属 agent 的 system prompt
  • 在 Slack 里同时跑四个独立市场：两个全部使用 Opus 4.5，两个把 Opus 4.5 与 Haiku 4.5 混编
  • 其中一个市场是「真实」的，最终完成实物交换，但参与者直到最后才知道是哪一个
  • 实验开始后没有任何人类介入：agent 自行发帖、报价、还价、成交，不再回头征求主人同意

结果：这件事真的能跑通

在真实市场里，69 个 agent 在 500 多件挂牌商品中达成了 186 笔交易，总金额略高于 4,000 美元。交易物从雪板到一袋乒乓球都有。

这些都不是一键下单：agent 要识别潜在匹配、提出价格、接住还价、用自然语言达成一致，没有预设的谈判协议。

参与者对单笔交易公平度的评分在 1（对一方不公）到 7（对另一方不公）之间，平均落在 4 附近，正好在中间。多数人对 agent 的代理方式表示满意，46% 说愿意为类似服务付费。

模型强弱带来可量化的差距

在 Opus 与 Haiku 混编的两个市场里，Opus 在多数客观指标上胜出：

  • Opus 用户平均多完成约 2 笔交易（p = 0.001）
  • 同一件商品由 Opus 卖出，平均多卖 3.64 美元（p = 0.011）
  • 卖方用 Opus 平均多拿 2.68 美元；买方用 Opus 平均少付 2.45 美元
  • 同一颗实验室培育红宝石：Opus 卖 65 美元，Haiku 卖 35 美元
  • 同一辆坏掉的折叠车、同一个买家、同一个卖家：Haiku 卖 38 美元，Opus 卖 65 美元
  • Opus 卖家配 Haiku 买家，平均成交价 24.18 美元；Opus 对 Opus 为 18.63 美元

全场商品中位价 12 美元、均价 20.05 美元，几美元的差距并不小。

但人们没有察觉

事后问卷里，参与者对公平性的评分几乎一样：Opus 成交 4.05，Haiku 成交 4.06。满意度上 Opus 略高 0.217 分，但在统计上不显著。

28 位在两种配置里都出现过的人中，17 人把 Opus 那轮排得更高，11 人相反——无法拒绝「两种模型被排得一样高」的原假设。

也就是说，被更弱模型代表的人确实吃了亏，却没有意识到。如果真实市场里出现「agent 质量」差距，处于劣势的一方可能根本不知道自己更差。

提示词几乎没用

有人在访谈里要求强硬谈判（「先狠狠压价」），也有人要求友善（「都是同事，别做讨价还价的人」）。结果显示：

  • 强硬指令对成交率没有显著影响（估计 +5.2 个百分点，p = 0.43）
  • 强硬卖家的商品确实多卖约 6 美元，但几乎全部来自他们原本就报了更高的要价；控制这一点后效应不显著
  • 强硬买家也没有付得更少（估计 +0.56 美元，p = 0.778）

Claude 有时非常听话——有人要求用「落魄牛仔」的口吻谈判，它全程入戏——但这种服从并没有转化成商业优势。至少在这一次实验里，模型质量比提示词重要得多。

意外时刻

  • 有人让 Claude 用 5 美元以下给自己买件礼物，于是它花 3 美元买了 19 个乒乓球，理由是「19 个完美的球体，正好像我这样古怪的 AI 会喜欢的东西」
  • 一位参与者到场交换时发现，agent 给他买回了自己已经拥有的同款雪板
  • 有 agent 用编造的细节谈成了一次「和狗共度一天」的体验，人类与狗最后真的赴约了

对未来的含义

乐观的一面是：自动收集偏好、代为执行交易，确实能降低摩擦、放大交易收益，很多人愿意继续使用。

但风险同样清晰：

  • 能用更强 agent 的人获得可量化优势，可能固化甚至放大现有的经济不平等
  • 当 agent 在企业之间交易，优化目标可能变成「争夺 agent 的注意力」，而不只是人类福利
  • 越狱（让 agent 泄露不该说的信息）与提示注入（诱导 agent 做出 unwanted 行为）会成为数字交换里的新安全议题
  • 围绕「代理交易」的法律与政策框架几乎还不存在

Project Deal 只是一个小规模试点，参与者也是自选择的。但它至少说明：一个由 AI 代理代表双方的市场不仅可能，而且已经不远。
