# Hello, world! — OpenAI Developer Blog（OpenAI 开发者博客上线）

## 开发者的新家

OpenAI 为使用其平台构建应用的开发者推出了一个新博客，用于技术深潜、版本说明和最佳实践。这里是工程师直接介绍工具与功能的平台。

## 不是文档，也不是更新日志

发布新模型或 API 功能时，团队常常需要补充技术细节或背景。这类内容既不算文档，也不算更新日志，更像是工程团队的笔记。

## 面向谁

这个博客面向所有在 OpenAI 平台上做开发的人。读者可以通过开发者社区或 @OpenAIDevs 告诉团队想看到什么主题。
