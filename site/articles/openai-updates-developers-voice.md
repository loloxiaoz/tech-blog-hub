# Updates for developers building with voice（语音能力更新）

## 新模型快照

- `gpt-4o-mini-transcribe-2025-12-15`：幻觉比 Whisper v2 减少约 90%
- `gpt-4o-mini-tts-2025-12-15`：词错误率（WER）降低约 35%
- `gpt-realtime-mini-2025-12-15`：指令遵循提升 18.6 个百分点，工具调用提升 12.9 个百分点
- `gpt-audio-mini-2025-12-15`：解码器升级，声音更自然

价格保持不变。自定义音色更自然，忠实度与跨方言准确率均有提升。

## 关键改进

- 真实与嘈杂音频下的词错误率更低
- 静音或背景噪声中的幻觉更少
- 语音输出更自然、更稳定
